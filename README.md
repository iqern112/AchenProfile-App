# My Portfolio

> เว็บไซต์แสดงผลงานส่วนตัว สร้างด้วย React + Vite

---

## เกี่ยวกับโปรเจค

เว็บไซต์พอร์ตโฟลิโอส่วนตัวสำหรับแสดงผลงาน ทักษะ และประสบการณ์ของฉัน ออกแบบมาให้ใช้งานง่าย รวดเร็ว และดูดีบนทุกอุปกรณ์

---

## ฟีเจอร์หลัก

- แสดงผลงานพร้อมรายละเอียด
- หน้าแนะนำตัวเอง (About Me)
- แสดงทักษะและเทคโนโลยีที่ใช้
- ช่องทางติดต่อ
- Responsive — รองรับทุกขนาดหน้าจอ

---

## เทคโนโลยีที่ใช้

| เทคโนโลยี | รายละเอียด |
|---|---|
| [React](https://react.dev/) | UI Library |
| [Vite](https://vitejs.dev/) | Build Tool & Dev Server |
| ESLint | Code Linting |

---


## 📦 Scripts ที่ใช้งานได้

```bash
npm run dev       # เริ่ม dev server
npm run build     # build สำหรับ production
npm run preview   # preview build ที่ทำไว้
npm run lint      # ตรวจสอบ code ด้วย ESLint
```
